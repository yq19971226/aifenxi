# 多视角回审：导航与分析卡片

**范围**：Sidebar、TopNav、ContextSidebar、UnifiedResultCard、nav 文案  
**结论**：**通过（有条件）** — 产品/UX、i18n、类型与数据、一致性视角达标；可访问性与 ContextSidebar/UnifiedResultCard 的少量 i18n 为可选改进。

---

## 1. 产品 / UX 视角

| 检查项 | 结果 | 说明 |
|--------|------|------|
| 侧栏一级/二级与当前路由高亮 | ✅ | `currentPath.startsWith(item.href)`、子项 `currentPath === sub.href`，逻辑正确 |
| 移动端底栏与抽屉入口 | ✅ | 仪表盘/共识/预警 + 更多；抽屉内账户（设置、活动）、系统（语言）结构清晰 |
| 抽屉内跳转后关闭 | ✅ | 设置/活动链接带 `onClick={() => setMobileMenuOpen(false)}` |
| 分析卡片信息层级 | ✅ | 信号 + 置信度、共识/支撑/阻力、推理、Key Findings、底部 ID 与引擎信息完整 |
| 无点位时的展示 | ✅ | Support/Resistance 用 `formatPrice` 回退为 "---"，推理无则 "—"，Risk Level 固定 "—" |

**结论**：通过。

---

## 2. i18n 视角

| 检查项 | 结果 | 说明 |
|--------|------|------|
| Sidebar 一级/二级/登录 | ✅ | `t(\`main.${item.key}\`)`、`getSubLabelKey` → admin.*/settings.*、`t('common.login')` |
| TopNav 底栏与抽屉 | ✅ | main.dashboard/consensus/alerts、common.menu/account/system、main.settings/growth |
| nav 三语种 key 完整 | ✅ | zh-CN / en / zh-TW 的 main、settings、admin、common、breadcrumb 与本次用到的 key 一致 |
| 链接带 locale | ✅ | 登录 `/${locale}/login`；Sidebar 一级/二级已改为 `/${locale}${item.href}`、`/${locale}${sub.href}` |
| ContextSidebar 文案 | ⚠️ 可选 | "System Status"、"Market Pulse"、StatusItem 的 label/value 仍为英文，可后续抽成 nav 或独立 namespace |
| UnifiedResultCard 文案 | ⚠️ 可选 | "Consensus"、"Risk Level"、"Support"、"Resistance"、"Analysis Reasoning"、"Key Findings"、"Updated"、"NSED-v4 Engine" 为英文，可做 i18n |

**结论**：核心导航与登录 i18n 通过；ContextSidebar、UnifiedResultCard 的英文为可选增强。

---

## 3. 类型与数据视角

| 检查项 | 结果 | 说明 |
|--------|------|------|
| ContextSidebar symbols | ✅ | `(dashboardData?.symbols ?? []).slice(0, 5).map(s => s.symbol)`，类型为 `SymbolOverview[]`，与 API 一致 |
| UnifiedResultCard 与 AnalysisReport | ✅ | confidence、strategy.entry_low/entry_high/targets、reasoning、report_id 回退与类型/StrategyData 一致 |
| formatPrice 空值 | ✅ | `val == null` 返回 "---"，非 number 用 `String(val)` |
| key_findings | ⚠️ 可选 | 组件已做存在性判断；若后端返回该字段，建议在 `AnalysisReport` 中增加 `key_findings?: string[]` |

**结论**：通过；key_findings 类型为可选补全。

---

## 4. 可访问性视角

| 检查项 | 结果 | 说明 |
|--------|------|------|
| 按钮可聚焦与键盘 | ✅ | 菜单按钮、关闭按钮为原生 button，可键盘操作 |
| 图标与文字并存 | ✅ | 底栏与抽屉均有文字标签，不依赖纯图标 |
| 关闭按钮无文案 | ⚠️ 可选 | 抽屉关闭为单一 X 图标，可加 `aria-label`（如 "Close menu"）以提升可访问性 |

**结论**：基本通过；关闭按钮 aria 为可选改进。

---

## 5. 一致性与可维护性视角

| 检查项 | 结果 | 说明 |
|--------|------|------|
| nav key 命名 | ✅ | main.* / settings.* / admin.* / common.* 与 Sidebar/TopNav 使用一致 |
| 设计系统类名 | ✅ | ContextSidebar 使用 `text-secondary-foreground`，与 tailwind 的 secondary.foreground 一致 |
| 链接构造方式 | ✅ | Sidebar、TopNav 均使用 `/${locale}/...`，与项目 localePrefix: 'always' 一致 |

**结论**：通过。

---

## 6. 本次回审中已修复项

- **Sidebar 链接带 locale**：一级 `href` 改为 `/${locale}${item.href}`，二级改为 `/${locale}${sub.href}`，避免在 localePrefix: 'always' 下依赖中间件重定向。

---

## 7. 多视角联合结论

| 视角 | 是否通过 | 备注 |
|------|----------|------|
| 产品/UX | ✅ 通过 | 导航与卡片信息层级、无点位回退均合理 |
| i18n | ✅ 通过（核心） | 导航与登录已 i18n；ContextSidebar/UnifiedResultCard 为可选 |
| 类型与数据 | ✅ 通过 | symbols、report 字段与回退正确；key_findings 类型可选 |
| 可访问性 | ✅ 通过（基本） | 可选：抽屉关闭按钮 aria-label |
| 一致性与可维护性 | ✅ 通过 | key 与类名、链接构造统一 |

**综合判定**：**通过**。当前改动满足多视角要求；可选改进可在后续迭代中按需完成（ContextSidebar/UnifiedResultCard 文案 i18n、key_findings 类型、关闭按钮 aria-label）。
