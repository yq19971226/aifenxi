## 一、核心定位

**OmniMind = AI 对抗 AI 的庄家视角多智能体分析预测系统**

核心卖点：系统 AI 给出信号后，庄家 AI（AdversarialAgent）站在庄家角度反推，
输出经过"压力测试"的修正策略和精准点位。用户拿到的不是裸信号，而是打过庄家博弈验证的策略。

### 2.2 综合分析 `/consensus`（独立页）

**顶部**：币种选择器 + 三模式说明卡片

| 模式 | AI 数量 | 主力 K 线 | 辅助参考 | 适合场景 |
|------|---------|-----------|----------|----------|
| 超短线 | 1 (Technical) | 5m + 15m | 1h | 合约短线，快进快出 |
| 日内博弈 | 5 并行 | 15m + 1h | 4h | 日内波段，费率套利 |
| 趋势布局 | 10 并行 | 4h + 1d | 1w | 现货中线，趋势跟踪 |

**AI 对抗流程**：
```
Step 1: 核心 AI 群并行分析 → 初步信号 + 初步点位
Step 2: 共识引擎汇总 → 方向 + 置信度 + 初步入场/止损/止盈
Step 3: 庄家 AI 拿到点位反推 → 识别打损区、假突破风险
Step 4: 输出修正后精准点位（非整数，避开整数关口）
```

**精准点位示例**：
```
修正入场: $96,187.50 - $96,432.20
修正止损: $94,156.80（避开 $95,000 整数打损区）
修正止盈: $98,773.40
庄家打损概率: 65%
防御建议: "不追高，等回踩支撑再入场"
```

**加载体验**：
- 分析需 20-40 秒，用流式进度条展示
- 逐个智能体完成时更新状态（Technical ✅ → Onchain ✅ → ...）

**会员分层**：
- 免费：看方向 + 置信度
- 专业：看结论 + 修正点位
- 旗舰：看完整 Step 1-4 博弈过程

### 2.3 剧本 `/playbook-sim`（独立页）

**顶部**：币种选择器 + 说明书（什么是剧本）

**AI 对抗推演**：
```
PlaybookAgent 识别当前剧本 → 庄家 AI 反推（是否诱饵）→ 概率修正 → 最终结论
博弈层到 L4 为实战极限
```

**剧本时间线对应**：

| 剧本类型 | 持续时间 | 对应 K 线 |
|----------|----------|-----------|
| 闪电打损 | 1-15 分钟 | 5m |
| 假突破 | 15 分钟~2 小时 | 15m + 1h |
| 资金费率收割 | 2-8 小时 | 1h + 4h |
| 震荡吸筹 | 1-3 天 | 4h + 1d |
| 拉高出货 | 3-7 天 | 1d |
| 长期布局 | 1-4 周 | 1d + 1w |

## 三、K 线数据系统

### 3.1 采集周期

| 周期 | 用途 | 新增 |
|------|------|------|
| 5m | 打损检测、闪崩分析、精准入场 | ✅ 新增 |
| 15m | 日内模式主力 | 已有 |
| 1h | 日内模式主力 | 已有 |
| 4h | 趋势模式主力 | 已有 |
| 1d | 趋势模式主力 | 已有 |
| 1w | 宏观趋势、长期支撑阻力 | ✅ 新增 |

### 3.2 多币种支持

- 当前：硬编码 `["BTCUSDT", "ETHUSDT"]`
- 目标：从数据库 `symbols` 表动态读取（约 10 个币种）
- 存储：TimescaleDB `klines` 表（upsert）+ Redis 缓存（TTL 10min）

### 3.3 历史数据回填

- 写 `kline_backfill.py` 脚本，一键拉取 12 个月历史数据
- Binance API 免费支持，每次最多 1000 根
- 10 币种 × 6 周期 ≈ 数分钟完成

## 四、会员权益体系

### 4.1 分层设计

| 功能 | 免费 $0 | 专业 $99/月 | 旗舰 $299/月 |
|------|---------|------------|-------------|
| AI 判断方向 | ✓ | ✓ | ✓ |
| 置信度 + 理由 | — | ✓ | ✓ |
| 修正后精准点位 | — | ✓ | ✓ |
| 庄家对抗推演 | — | 结论 | 完整报告 |
| 防御建议 | — | 基础 | 详细+危险区间 |
| 剧本推演 | — | 匹配结果 | 完整推演过程 |
| 历史准确率 | 近 7 天 | 近 30 天 | 全部 |
| 实时预警 | — | 邮件 | 邮件+TG+WebSocket |
| 策略回测 | 7 天 | 30 天 | 180 天 |

### 4.2 免费用户体验

- 每天 1 次日内博弈体验（5 个 AI 并行）
- 后台可配置开关：`free_daily_intraday_trial`
- 目的：让用户尝到多 AI 分析的甜头，促进转化

### 4.3 内容锁定

- 使用模糊遮罩 + 升级提示按钮
- 比次数限制更有效——用户知道有好东西看不到，痒
