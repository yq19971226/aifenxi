# 多视角回审：指挥中心、综合分析卡片与移动端布局

## 一、布局 / 响应式视角

### 1.1 主布局 (layout.tsx)

| 项 | 结论 | 说明 |
|----|------|------|
| 移动端纵向堆叠 | ✅ 合理 | `flex-col md:flex-row` 使移动端为单列：顶栏 → 内容区，避免顶栏与内容并排导致左侧留白。 |
| 桌面端行为 | ✅ 保持 | `md:flex-row` 下仍为 Sidebar + 内容区 + ContextSidebar，与改前一致。 |
| 防溢出 | ✅ 合理 | 根节点 `overflow-x-hidden`，内容区与 main 均设 `min-w-0`，可避免 flex 子项撑出横向滚动。 |
| 潜在点 | ⚠️ 留意 | TopNav 仍为 Fragment（header + nav + drawer），在 flex 中会展开为多个子节点；当前在 `flex-col` 下 header 与内容区顺序正确，若以后调整 DOM 顺序需再测移动端。 |

### 1.2 TopNav 移动端

| 项 | 结论 | 说明 |
|----|------|------|
| 顶栏占满宽 | ✅ 合理 | `w-full min-w-0 shrink-0` 保证在纵向布局中顶栏占满一行。 |
| 底栏触控 | ✅ 合理 | `min-h-[44px] min-w-[44px]` 满足常见触控最小尺寸，文案 `text-xs` 较原 `text-[10px]` 更易读。 |
| 抽屉 | ✅ 未动 | 仍为 `fixed inset-0`，不影响主布局流。 |
| 无障碍 | ⚠️ 可加强 | 菜单按钮已加 `type="button"`；搜索按钮暂无 `aria-label`，可后续补上。 |

## 二、i18n / 可访问性视角

### 2.1 综合分析卡片 (UnifiedResultCard)

| 项 | 结论 | 说明 |
|----|------|------|
| 文案来源 | ✅ 统一 | 共识/风险/支撑/阻力、一致/评估/关键位、分析推理/关键发现、更新/引擎/ID/永续 均走 `t("consensus.card.*")` 与 `t("consensus.signals.*")`，三语已补全。 |
| 信号标签 | ✅ 合理 | 看多/看空/中性 使用既有 `signals.bullish/bearish/neutral`，与共识页一致。 |
| 缺失 key | ⚠️ 需避免 | 若某 locale 缺少 `card.*` 会 fallback 成 key 路径；当前 zh-CN/zh-TW/en 的 consensus.json 均已含 `card`，无缺口。 |

### 2.2 看板与规则引擎

| 项 | 结论 | 说明 |
|----|------|------|
| 规则结果 | ✅ 合理 | 可操作/风险/观望 使用 `dashboard.ruleVerdict.*`，三语一致。 |
| 数据与代码分离 | ✅ 合理 | 规则逻辑在 `dashboardRuleEngine.ts`，阈值与等级为常量，便于后续调参或扩展。 |

### 2.3 仍为英文或未 i18n 的部分

| 位置 | 内容 | 建议 |
|------|------|------|
| TopNav 顶栏 | "AXIOM" 品牌名 | 可保留；若需可加 nav.appName 等 key。 |
| 卡片内 | 报告中的 `report.symbol`（如 BTCUSDT）、`report.strategy?.reasoning`（后端返回） | 符号可保留；推理文案依赖后端多语言或统一中文，非本次前端 i18n 范围。 |
| 单位 "s" | 执行时间 0.03s | 可加 common.seconds 等，非必须。 |

| 项 | 结论 |

## 四、边界与回归风险

### 4.1 移动端

| 风险 | 评估 | 建议 |
|------|------|------|
| 平板 (768px) | `md:` 断点下会切为 row，Sidebar 出现，与当前设计一致。 | 若有「平板也要单栏」需求，可再考虑 lg 或单独断点。 |
| 横屏 | 仍为 flex-col / flex-row 按断点，无额外逻辑。 | 真机横屏可抽测一次。 |
| 安全区 | 底栏已有 `pb-safe`，内容区 `pb-20` 为底栏留白。 | 保持即可。 |

### 4.2 桌面端

| 风险 | 评估 |
|------|------|
| 内容区宽度 | `md:pl-[64px]` 仅桌面生效，主内容与右侧 ContextSidebar 未改，无回归。 |
| 共识页/看板 | 仅用现有数据与文案 key，无新接口或路由变更，回归面小。 |

### 4.3 数据与权限

| 风险 | 评估 |
|------|------|
| overview 为空 | 看板已处理 `symbols.length === 0` 的空态与提示。 |
| 报告无 strategy | 卡片已用 `report.strategy?.reasoning ?? "—"` 等，不会报错。 |

## 五、小结与可选后续

- **布局**：移动端改为纵向堆叠 + 内容区全宽与防溢出，逻辑正确，可解决「左侧留白」；桌面端行为保持不变。
- **i18n**：综合分析卡片与看板规则结果已按三语接入，无新增硬编码英文。
- **可读性**：卡片与底栏字号已加强；看板行内置信度仍为 10px，可按统一规范再提一档。
- **可选后续**：搜索按钮 `aria-label`；看板 `RuleResultRow` 右侧置信度改为 `text-xs`；若需品牌名 i18n 再补 nav 文案。

总体判断：当前改动与设计意图一致，未发现逻辑错误或明显回归风险；建议在真机与多分辨率下再跑一轮验收。
