# Design Spec — 登录页高端重设计

## 设计哲学

**对标产品**: Linear / Mercury / Ramp / Vercel — 不是"暗色科技风"，而是"安静的自信"。

**核心原则**:
1. **克制** — 去掉一切装饰性元素（渐变光斑、图标 logo、紫色泛滥）
2. **排版即设计** — 用字重、字号、间距、对比度构建层次，不依赖颜色
3. **留白即奢侈** — 宁可空着，绝不填满
4. **一个重点** — 整个页面只有一个视觉焦点：CTA 按钮
5. **无感动效** — 动画只用来消除突兀，不用来吸引注意

## 当前问题诊断

| 问题 | 原因 | 解决 |
|------|------|------|
| Brain 图标 + indigo 背景 | 典型 AI 模板套路 | 去掉图标，用纯文字 wordmark |
| 紫色模糊光斑背景 | 每个 AI 生成页面都有 | 去掉，纯色背景 + 极微噪点纹理 |
| 居中小卡片 | 过于常规 | 左右分屏布局（左品牌 / 右表单） |
| 粗糙的 tab 切换 | 按钮式 tab 不够精致 | 底部带线的文字 tab |
| 紫色按钮 | AI 味 accent | 白色按钮 + 黑色文字（反转色权重） |
| 标签全大写 + 粗体 | 过度设计 | 正常句式，zinc-400 色 |
| "多智能体市场分析系统" 副标题 | 太工程师思维 | 更优雅的品牌语 |

### 响应式
- **≥1024px**: 左右分屏 (左 45% 品牌面 / 右 55% 表单面)
- **<1024px**: 堆叠，品牌区收缩为顶部一行 wordmark + tagline

## 视觉规格

### 左侧品牌面
- **背景**: `#09090b` 纯色 + CSS noise texture (opacity 3%)
- **Wordmark**: `OMNIMIND` 字母间距 `0.3em`, font-weight 300, font-size 13px, zinc-400
- **Tagline**: "Institutional-grade market intelligence" — font-size 28-32px, font-weight 500, zinc-100, line-height 1.2, 最多两行
- **底部**: 极淡 `©2025` 版权 — zinc-600, font-size 12px
- **分隔**: 左侧右边缘 1px `border-white/[0.06]` 竖线

### 右侧表单面
- **背景**: `#0c0c0f` (比左侧略亮一档)
- **表单容器**: 无边框无卡片，直接在面板上排列，max-width 360px, 垂直居中
- **Tab**: 两个文字链（"登录" / "注册"），选中态 zinc-100 + 底部 1px accent 下划线，未选中 zinc-500
- **Label**: font-size 13px, font-weight 400, zinc-400, 普通大小写 (非全大写)
- **Input**: 
  - 背景 transparent
  - 底部边框 1px zinc-800
  - focus: 底部边框变 zinc-400, 无 box-shadow glow
  - 无圆角（或极小 2px）
  - padding: 12px 0 (无左右 padding，左对齐)
- **CTA 按钮**:
  - 背景: `#fafafa` (白色)
  - 文字: `#09090b` (黑色), font-weight 500
  - 圆角: 6px
  - hover: `#e4e4e7`
  - 高度: 44px
  - 无图标，纯文字 "继续"
- **次要链接** ("忘记密码？"): zinc-500, hover zinc-300, font-size 13px

### 色彩纪律
- **禁止**: indigo/purple 在登录页出现
- **Accent**: 只在 tab 下划线用一次 `#fafafa` (白色即 accent)
- **Error**: `#ef4444` 文字，无背景色块
- **Success**: `#10b981` 文字，无背景色块

### 动效
- 页面加载: opacity 0→1, duration 300ms, ease-out (无位移)
- Tab 切换: 表单区 opacity 过渡 150ms
- 无 framer-motion（原生 CSS transition 即可，减少依赖感知）

### 排版
- 全部使用 Inter
- 不使用 monospace（除验证码输入）
- 不使用 uppercase labels
- 不使用 tracking-wider

## 不修改的部分

- 所有业务逻辑（登录/注册/忘记密码）保持不变
- useAuth hook 不变
- 路由逻辑不变
- referral code 功能保留
- URL 参数 ?ref= 功能保留

## 文件影响

- **修改**: `frontend/app/login/page.tsx` — 完全重写 JSX/样式
- **不动**: `globals.css`, `tailwind.config.ts`, 其他组件
